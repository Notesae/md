# 留一点时间，给阅读。

把目光交还给文字。这是一份 **MD 阅读样例**，用于验证中文排版与 Markdown 语法，并非用户文档。

## 从一篇文章开始

点击左上角的“打开文件”，或者把 Markdown 文件拖入窗口。你也可以打开文件夹，让笔记留在原来的位置。

> 好的阅读界面，应当让人忘记界面的存在。
>
> 原始文章始终只读，阅读进度与偏好独立保存。

### 一点结构，一点秩序

1. 左侧浏览文件与最近阅读。
2. 右侧目录帮助你在长文中找到方向。
3. 按 `Ctrl + F` 搜索正文，按 `Esc` 回到阅读。

## 让内容有自己的节奏

| 内容 | 呈现方式 |
| :--- | :--- |
| 中文长文 | 舒适行高、适度留白 |
| 代码 | 保留缩进，按需高亮 |
| 公式 | 正文先出现，再补充排版 |
| 本地图片 | 按需加载，保持原有位置 |
