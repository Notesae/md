# 架构与初始版本实施计划

完整范围以 SPEC.md 为准，所有阶段完成后才能宣告初版完成。每个阶段执行针对性验证，检查暂存差异，独立提交并推送 `Notesae/md`。不使用 Maven。

1. **工程基线**：保存规格、模块边界、风险、任务与协作约定；初始化 main 和远程。验证远程为空及推送结果。
2. **可运行骨架与启动存储**：锁定依赖，建立构建脚本；Rust 核心测试先行，原生首次选目录与自定义 WebView 数据路径贯通。验证前端构建、Rust 测试和桌面启动。
3. **只读阅读闭环**：选择/拖放/参数打开、全文解析分块展示、文件夹按需展开、目录、图片安全、外部链接。验证扩展样本和桌面实际操作。
4. **阅读体验**：搜索、复制、高亮、公式、主题/宽度/字号、最近记录/位置/布局与外部变更刷新。验证竞态、长文、刷新与状态恢复。
5. **存储管理与迁移**：分类统计、预算/清理、重启清理 WebView、迁移协议、失败恢复与残留重试。验证中断注入及目录边界，不触碰用户原文。
6. **交付验证**：release 与安装包、文件关联、固定性能样本、实际写入审计、100 次切换、使用说明/变更日志和验收报告。保留完整证据，未满足性能目标时继续定位优化。

## 风险

- 当前机器缺少 Rust/MSVC，需在工作盘建立工具链；系统组件安装可能需要额外环境授权。
- WebView2 已安装；进程退出、文件占用和迁移重启需要 Windows 实测。
- 长文 DOM、高亮与公式成本须分段调度并实测；不以空壳或仅首屏样本替代完整功能。
- 迁移协议先通过无界面的核心故障注入，再连接设置页。
