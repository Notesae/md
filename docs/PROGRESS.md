## 性能诊断

以下是优化前最新一轮的单次 release 诊断样本。文件系统缓存为热缓存，不能据此宣称 P95 达标。

| 文档 | 持久解析缓存 | 首屏 |
| --- | --- | --- |
| 1,000,000 字节 | 关闭 | 335.4ms |
| 10,000,000 字节 | 关闭 | 454.4ms |
| 1,000,000 字节 | 命中 | 1,404.4ms |
| 10,000,000 字节 | 命中 | 10,973.5ms |

10MB 缓存命中中，缓存读取约 9,433ms；同尺寸重新解析约 34ms。已据此修改 JSON I/O，并针对大文档长任务调整离屏布局。优化后尚未正式复测，1MB 首屏 200ms 等原定目标仍保留。

诊断环境：Windows 11，系统版本 10.0.26200，i7-12700，20 个逻辑处理器，约 47.7GiB 内存，WebView2 155.0.4283.62；采样窗口 1280×860，缩放 100%。
