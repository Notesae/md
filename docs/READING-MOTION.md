# 阅读层级与可中断动效

基线为 v0.1.1 / ad483c41fc87badbfa4427f7bc4b7ebcecd97aca。本轮保留暖白墨绿、深色、三栏及只读阅读定位，聚焦正文层级、工具状态、搜索浮层和维护确认。

## 用户行为

- 一级标题、引导段和章节标题有更清晰的字号、色彩及间距层级；目录与设置辅助文字更易读。工具栏的悬停、按压、禁用、展开及键盘焦点各有明确反馈。
- 搜索置于零高度 sticky 锚点上的浮层，打开不推移正文。无结果时禁用前后导航；关闭返回阅读区，进入设置时退出搜索键盘路径，返回后恢复实际状态。
- 窄窗目录打开后承接焦点；Escape 返回触发按钮，选择标题后回正文。关闭或跨断点隐藏后立即 inert，不留下隐藏焦点；桌面目录偏好与临时抽屉分开。
- 维护确认保持原有准备、提交和取消边界。状态按 ready/preparing/working/error 呈现，确认按钮提供 aria-busy；准备与失败区预留两行高度。关闭即时 inert，焦点由原生 dialog 返回入口；退场画面及遮罩不拦截指针。

## 动效约定

| 场景 | 进入 | 退出 | 属性 |
| --- | --- | --- | --- |
| 控件反馈、维护状态色 | 120ms ease-out | 按压 90ms | 背景、文字、边框色 |
| 搜索、通知、维护确认及遮罩 | 140ms cubic-bezier(.16,1,.3,1) | 90ms ease-in | opacity，离散 display/overlay |
| 窄窗目录 | 160ms cubic-bezier(.16,1,.3,1) | 90ms ease-in | opacity、最大 8px 横移、离散 display |

视觉过渡使用 CSS，隐藏语义、取消、焦点和输入不等待动画结束。不引入动画定时器或结束回调，因此重复开关直接按最新 DOM 状态中断。画布裁剪避免目录位移暂时增加页面滚动宽度。正文、阅读位置和主题整页不参与入场动画。

仅在 prefers-reduced-motion:no-preference 下启用过渡；reduce 分支显式 transition:none，确保运行中更改偏好也取消已开始的过渡。不支持离散过渡的浏览器直接切换。未增加动画库、无限循环、重滤镜或永久 will-change。

## 验证与范围

本轮在内置浏览器使用实际前端源码、Reader 和 CSS，原生 IPC 使用合成文档及内存状态。基线截图在改动前重新捕获。1280×720 与 800×580、浅深主题及 28px/1200px 偏好均已检查。浏览器结果包括：搜索推移由 47px 降为 0；目录入场 0/40/90/160ms 页面宽度始终 800；维护 ready/error 高度均为约 302.3px；取消及重试成功后焦点返回缓存入口。

帧序列由开发夹具中的时间轴暂停**真实 CSS 过渡**后截图，并记录时间点和 computed style；不是实时视频或帧率证明。减少动态测试准确模拟两组 CSS 媒体分支的匹配切换，验证进行中 opacity/transform 立即落到最终状态；未更改或验证 Windows/浏览器实际媒体偏好的传播。

新增四项控制器回归覆盖快速反复开关、隐藏焦点及断点切换、维护忙碌状态和取消后立即重开。截图、逐帧数据和完整步骤报告位于本次 Codex 任务产物 md-motion-review/REVIEW.md；测试夹具、时间轴和截图不随产品打包。
