# 纸页动效语言

本文取代 [READING-MOTION.md](READING-MOTION.md) 中的动效约定。样式令牌与规则位于 `src/styles.css` 末尾，滑行位于 `src/glide.ts`，覆盖式滚动条位于 `src/scrollbars.ts`。

## 隐喻

界面是一张放在暖色桌面上的纸。所有动效都回答一个问题：**一张真实的纸在这里会怎么动？**

- 纸有重量：起步快、停稳慢，最后一段明显“落定”。
- 纸有厚度：被拿起时离桌面更远，投影更深、更柔；放下时投影收紧。
- 纸只会平移：不弹跳、不缩放；唯一的旋转是通知纸条进场时 1.2° 的歪斜，像随手放下的便签被摆正。
- 纸面是稳定的：切换页面时纸本身不动、不透明度不变，只有纸上的内容换掉。整张纸一起淡出会透出桌面，看起来像闪烁。
- 纸从它所在的地方来：侧栏从左缘，目录从右缘，查找栏从纸顶，通知与对话框从桌沿下方。

## 原则

1. **允许慢，但不拖沓。** 页面与浮层 520–680ms，悬停反馈 200ms；退场始终比进场快（120–200ms），关闭和取消立即生效。
2. **正文静止。** 阅读与滚动期间不播放装饰动画；只有打开一篇新文章时首屏浮起一次。自动刷新不播放。
3. **跳转是滑行，不是瞬移。** 目录跳转、搜索结果切换与“回到开头”都滑到目标位置；搜索结果首尾循环。
4. **层次靠投影，不靠颜色。** 悬停抬起 1px 并加深投影，按下贴回桌面。
5. **随时可打断，从不卡住。** 视觉过渡全部由 CSS 或一次性 Web Animations 驱动；滑行在滚轮、触摸、按键或指针按下时立刻交还控制。`hidden`、`inert`、焦点与输入从不等待动画。翻页的淡出最多等 260ms、主题过渡最多等 400ms 拿到旧画面，渲染暂停（如窗口被遮挡）时直接切换。
6. **尊重系统。** `prefers-reduced-motion: reduce` 时移除全部过渡与动画；视图过渡与滑行由脚本直接跳过，跳转瞬间完成。

## 令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-press` | 120ms | 按压 |
| `--dur-quick` | 200ms | 颜色反馈、所有退场 |
| `--dur-base` | 360ms | 投影与抬起、进度、浮层遮罩 |
| `--dur-slow` | 520ms | 栏宽推拉、目录短线、查找栏、子目录展开 |
| `--dur-page` | 680ms | 页面分段浮现、通知、对话框 |
| `--dur-theme` | 900ms | 主题切换的光线扫过 |
| `--ease-paper` | cubic-bezier(.22, 1, .36, 1) | 纸张：快起慢停，长落定段 |
| `--ease-glide` | cubic-bezier(.65, 0, .35, 1) | 推拉：起止都缓，用于栏宽 |
| `--ease-standard` | cubic-bezier(.2, 0, 0, 1) | 颜色与透明度 |
| `--ease-exit` | cubic-bezier(.55, 0, .75, .1) | 退场：慢起快走 |
| `--lift` / `--slide` | 10px / 14px | 浮层垂直位移 / 面板水平位移 |
| `--shadow-rest` / `-lift` / `-float` | 三级投影 | 静置、抬起、悬浮 |

滑行（`glide.ts`）使用起止都缓的五次曲线，时长 `min(900, 420 + √距离 × 12)` ms；距离超过约 2.4 屏时先无动画靠近到 1.2 屏外再滑入，避免掠过整篇文档触发大量排版。每帧重新测量目标位置，适应延迟排版带来的高度变化。

## 场景

| 类别 | 场景 | 表现 |
| --- | --- | --- |
| 纸的物理 | 主次按钮、引导页位置卡片、主题预览 | 悬停上移 1px，投影由静置变为抬起；按下 120ms 贴回 |
| | 侧栏当前文章 | 成为当前项时从 2px 高处带着投影落定（520ms） |
| 位置 | 目录当前章节 | 独立短线沿竖线滑到新章节（520ms），目录列表随之滑动保持可见 |
| | 阅读进度 | 进度条宽度 360ms 跟随 |
| 滑行 | 目录跳转、搜索上一个/下一个、回到开头 | 正文滑到标题顶部或结果所在行中央；搜索首尾循环 |
| 展开 | 子目录 | 高度从 0 展开到内容高度（520ms），子项自上 6px 浮现，箭头转向 |
| 面板 | 侧栏、目录 | 栏宽 520ms 推拉；内容先向自己的边缘退 14px 并淡出，回来时延迟 120ms 再浮现 |
| | 窄窗目录抽屉 | 自右 14px 滑入（520ms），200ms 退出 |
| 浮层 | 查找栏 | 自纸顶落下 10px（520ms） |
| | 通知 | 自下 18px、歪斜 1.2° 滑入后摆正（680ms） |
| | 确认对话框 | 自下 20px 轻放（680ms），遮罩 360ms 淡入 |
| 页面 | 欢迎页、设置页、首次引导页 | 各部分依次自下 12px 浮现（680ms，间隔 40–70ms） |
| | 打开文章 | 首屏自下 14px 浮现（640ms），只在打开时播放一次 |
| 翻页 | 进出设置 | 纸面本身不动：当前内容 180ms 上移 6px 淡出，再换上新内容。设置各分组依次浮现；回到正文时正文与文末自下 14px 浮起（640ms）；目录随之淡出与回归 |
| 光线 | 主题切换 | 视图过渡：新配色像一道斜光从右侧（切换按钮一侧）扫过整窗（900ms，柔边约窗宽四分之一）；旧配色留在下面不淡出，避免整窗闪烁 |
| 细节 | 代码复制按钮 | 悬停或聚焦代码块时浮现 |

## 覆盖式滚动条

- 原生滚动条隐藏（`scrollbar-width: none`），不占布局宽度。拇指浮在内容之上，贴容器右缘与下缘，宽 6px，悬停或拖动时加粗到 9px。
- 滚动时浮现，静止约 1.1 秒后用 360ms 淡出；指针靠近容器右缘或下缘 16px 内时提前浮现，可直接拖动。
- 通过捕获阶段统一监听所有元素的滚动，按需为容器建立覆盖层，因此正文、侧栏、目录、代码块、表格与设置页都自动获得同样的滚动条。轨道按容器与其裁剪祖先的交集定位，嵌套代码块滚出正文时拇指一并被裁掉。
- 淡出计时是唯一使用的定时器，只控制可见性；可见期间按帧跟随布局，全部淡出后停止。

## 不做的事

- 不为正文块、图片加载、搜索高亮、主题以外的配色变化和窗口尺寸变化添加动画。
- 不引入动画库、无限循环动画、模糊滤镜或常驻 `will-change`。
- 不让任何功能依赖动画结束事件。

## 验证

已在浏览器预览中用合成数据检查：覆盖式滚动条出现与淡出、原生滚动条宽度为 0、目录短线位置、滑行终点、搜索循环计数、翻页与主题切换在渲染被节流时也能按兜底时限完成且不报错。预览面板在后台会节流动画帧，因此**未测量帧率与实际流畅度**，需在 WebView2 桌面窗口中目测；也未验证系统“减少动态效果”在 WebView2 中的实际传播。
