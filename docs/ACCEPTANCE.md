## 不能替代的证据

- 网页截图不能证明 WebView2 数据重定向或原生选择器行为。
- 开发/调试构建不能用于 release 性能目标。
- 核心单元测试不能证明进程退出、文件关联或卸载行为。
- 默认引导被测试目录覆盖时，不能声称标准安装的系统盘写入审计通过。
- 少量样本不能推导稳定 P95；未记录的成绩按未测处理。
