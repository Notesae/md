# MD 0.1.2（预发布）

本版基于 0.1.1，整合阅读层级、工具反馈、搜索浮层与可中断弹层精修。仓库和发布附件保持私有可见性；旧版本保留。

## 本版变化

- 调整标题、引导段、章节间距与辅助文字，沿用暖白墨绿和深色主题。浅色侧栏辅助文字对比度由约 4.37:1 提高至 4.64:1。
- 搜索浮层打开时保持正文位置；无结果时禁用前后导航。工具栏的悬停、按压、展开和键盘焦点反馈更清楚。
- 控件反馈 120ms，弹层入场 140ms，窄窗目录 160ms，退场 90ms。隐藏、取消、焦点返回和输入释放立即生效；减少动态分支取消在途过渡。
- 维护确认的准备、执行、错误与重试状态更清楚，常见错误和准备状态保持同一高度；快速取消重开不会被旧结果关闭。
- 保留既有审计的目录归属保护、重解析点检查、卸载副本等待、退出码隔离和失败证据留存。旧验收与组合验证 PR 已按内容等价性核对归档。

## 验证边界

- 对应提交、代码树、CI 运行和包哈希见 BUILD-INFO.json 与 SHA256SUMS.txt。打包步骤位于前端、Rust、桌面编译和隔离安装审计成功之后。
- 本轮阅读界面证据来自实际前端加合成 IPC；11 张动效帧是暂停真实 CSS 过渡后的采样，不证明实时帧率或原生 WebView2 表现。真实系统减少动态设置、Narrator 与系统缩放仍未建立新验收。
- 安装审计只覆盖当前用户安装/关联、保留卸载、删除应用数据卸载和升级保留四条隔离路径；其 specPassed 仍为 false，不代替首次选目录、取消退出和系统盘全程写入验收。
- 完整原生迁移与正式性能仍有缺口。历史 1MB 进程组私有工作集为 312.5MiB，高于 SPEC 的 250MiB；本轮没有新的原生内存测量，不宣称已达标。
- 本版没有新增或配置 GitHub 客户端登录授权。应用内私有更新链路未实测；发布到私有 Release 只表示具备仓库权限的账户可手动下载附件。

## 附件

- MD_0.1.2_x64-setup.exe：Windows x64 当前用户安装包。
- MD_0.1.2_x64-standalone.zip：独立程序与使用说明；仍使用应用的数据目录选择，原始文章保持只读。
- BUILD-INFO.json、RELEASE-NOTES.md、SHA256SUMS.txt：构建来源、说明与四个载荷文件的 SHA-256。
