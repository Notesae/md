# 公开 Release 应用内更新

MD 的更新入口位于“设置 → 应用更新”。仓库已由所有者改为 public；应用从 `Notesae/md` 的公开 GitHub Release 获取版本与安装包，不使用 GitHub App、Client ID、OAuth、令牌或浏览器登录会话，也不上传文档、阅读路径或偏好。

## 用户流程

- 每次应用启动默认“仅稳定版”。检查是手动操作，打开设置不会访问 GitHub。
- 稳定通道使用 GitHub latest Release，并同时排除 GitHub 预发布标记及语义预发布版本。“稳定版与预发布”需明确选择，只在本次会话有效；按语义版本从最近 100 条公开记录中选择更新版本，满 100 条时停止并提示打开发布页，不假定列表已完整。两个通道均不自动降级，build metadata 不触发更新。
- 发现版本后显示版本号、预发布标记、Windows x64 安装包大小与纯文本说明。点击下载后显示实际字节进度；下载可在后台继续，取消会停止请求并清理受控暂存。关闭 MD 会请求取消未完成操作。
- 下载完成后仍不安装。用户再次点击“安装更新…”并确认，应用保存阅读位置和偏好、重验安装包、打开交互式当前用户安装向导，然后退出以释放程序和数据锁。没有 `/S` 静默参数，没有 `/DELETEAPPDATA`，仅使用既有 NSIS `/UPDATE` 数据保留语义。
- 独立程序不会在原目录自覆盖；安装包交接使用当前用户安装位置。启动安装器失败时保留当前应用和校验后的下载，用户可以重试或丢弃。

## 来源和完整性边界

初始 API 与附件地址固定为本仓库。附件必须严格匹配 tag 对应的 `MD_<version>_x64-setup.exe`、`BUILD-INFO.json` 和 `SHA256SUMS.txt`。拒绝重复、不完整、超限、无 SHA-256 digest 或跨仓库的附件。

请求只使用 HTTPS，保留系统证书与主机校验；重定向限 GitHub 及其已知 Release CDN 主机，拒绝明文、自定义端口、userinfo、本地地址和任意用户内容域。临时 CDN 查询串不会进入错误提示或日志。GitHub 返回 403/429 时显示限流与可用的重试时间，不自动重试、不切换身份或代理绕过限制；公开发布页保留为用户主动打开的入口。

API digest、校验清单和构建记录必须交叉一致。安装包以流式字节计数及 SHA-256 核验，安装前再次核验长度、摘要、普通文件路径和 MZ 文件头；Windows 维持拒绝写入/删除的读取句柄直到交接成功。安装路径和参数由后台决定，前端不能提交 URL 或任意可执行路径。

这套校验基于同一公开 GitHub 发布来源及 HTTPS，**不是独立的发布者数字签名**。现有安装包未建立 Windows 代码签名，系统可能提示未知发布者。Tauri 官方 updater 需要签名密钥及签名制品；本实现没有创建密钥、关闭签名校验或启用该插件，而是使用现有安装包的明确用户交接流程。它也不承诺安装器开始替换文件后的自动回滚。

## 数据位置与失败保护

只在用户选择的数据根 `temp/md-update-<UUID>/` 下写入三个固定文件名：归属标记、下载中的安装包、校验后的安装包。安装包上限为 60MiB；写入前计入现有临时占用，遵守 64MiB 常规临时预算并检查剩余空间。部分下载不会被当成完成包。

暂存带应用、根实例和 UUID 标记以及排他锁。清理先验证本地路径及归属、拒绝符号链接或重解析点、陌生条目和子目录；仅逐一删除固定文件，不递归删除用户目录。仍活跃的暂存或被安装器占用的包保留，下次下载准备时再次清理。异常残留会计入现有存储统计，不将任意 `md-update-*` 名称视作删除授权。

下载与安装交接复用存储维护锁，迁移、重置与交接不会并发修改数据根。安装交接前保存失败则不启动安装器；校验失败不会启动，网络或写盘失败清理未完成暂存。此入口不会删除原始 Markdown 或附件，也不把系统安装器、WebView2 与 Windows 自身写入宣传为“系统盘零写入”。

## 发布和验证

手动发布 workflow 沿用 tag + 成功 Quality run ID 的精确来源校验；仓库所有者已将仓库公开，发布脚本相应要求公开的 `Notesae/md`，保留所有旧 Release，且不修改仓库可见性或默认权限。未来版本仍需正常更新应用版本和 tag，不需要每次修改发布 workflow。

控制器回归和 `node tests/update-browser.mjs` 使用合成 IPC。浏览器脚本只运行真实更新组件与产品 CSS，拦截非本机请求，检查手动检查、字节进度、取消、真实 dialog 的焦点/Escape、保存失败及明确交接后的失败恢复；Windows Quality 将截图和摘要归档为 `md-updater-ui-*`。390px 截图仅验证组件容器，MD 桌面窗口的最小尺寸仍为 800×580。安装确认还会保存进入设置时捕获的阅读位置，避免异步保存期间继续滚动的位置遗漏。

Rust 包校验与交接回归只创建隔离的伪安装包并注入失败/成功启动结果；字节流回归通过本机 HTTP 夹具覆盖进度、损坏、截断、超量和取消清理，不放宽产品 HTTPS 限制，绝不执行该文件。本机真实安装、卸载、用户当前应用替换均不作为自动测试步骤。真实版本 A→B 安装、用户取消向导、SmartScreen/未知发布者提示、断电或安装器中断恢复仍需单独隔离 Windows 验收；不得以单元测试、截图或编译成功代替这些结果。

参考：[Tauri updater 的签名要求](https://v2.tauri.app/plugin/updater/#signing-updates)、[GitHub Release API](https://docs.github.com/en/rest/releases/releases)、[reqwest 超时配置](https://docs.rs/reqwest/0.13.5/reqwest/struct.ClientBuilder.html#method.read_timeout)。
