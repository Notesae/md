1. **图片错误恢复：已修复。** 合成坏字节和暂时拒绝的 `read_image` 在实际前端中都只留下错误文本，没有重试入口；解码错误的 Blob URL 仍留在资源表。现在失败立即释放 URL，显示有状态语义的错误说明和“重新加载图片”，重试只重读该图片。进行中的按钮禁用，避免重复读取。截图 `01` → `02` → `03`。
2. **键盘和窄窗口：已修复并局部验证。** 重试按钮消失后焦点曾落到 BODY；现在承接到恢复后的图片，再次失败时回到重试。用户已转到其他控件时不抢回焦点。追加回归确认并修复了聚焦图片离屏回收时再次失焦的问题：释放前交回阅读区以继续键盘滚动。800×580 深色界面控件可达、无水平溢出；只复用原有 secondary 按钮、颜色和减少动效偏好下的交互样式，未添加布局动画。截图 `04`、`05`。未声称完整屏幕阅读器或无障碍验收。
3. **增强 Worker 异常恢复：已修复。** 修复前 Worker 的启动/投递异常会抛出，运行错误也不会清空任务或终止线程。现在本篇降级一次，清空队列、解绑并终止失败 Worker，保留代码和公式原文；重新打开后重试。旧 Worker 的迟到事件不能影响新文章。实际前端通过一次启动故障后重开，恢复代码高亮及 KaTeX。截图 `06` → `07`。
4. **资源生命周期：合成回归通过。** 100 次换文与故障循环累计创建/撤销 URL 各 100 个，创建/终止 Worker 各 100 个；最终保留 URL、待处理任务和文档元数据均为 0。该结果证明受测生命周期的结构约束，不是原生工作集或 GC 测量。
