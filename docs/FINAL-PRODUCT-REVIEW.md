## 对用户的实际改善

- 关闭、重开、搜索和设置之间的切换有一致的标题、进度、焦点及空状态，不再把旧页面状态带到下一篇文章。
- 图片失败可以逐张重试；代码/公式增强失败时保留可读原文，重开可恢复。成功恢复后焦点有承接。
- 存储维护准备阶段可以取消，已提交后不会伪装取消成功；失败可重试，返回阅读不会被隐藏确认框阻塞。
- 本轮补修：打开失败后成功换文，旧的持久错误曾继续显示；增强恢复后也会短暂保留旧警告。现在成功换文或关闭时只清除旧文章提示，新的文章错误及全局未保存/存储警告仍保留。取消文件选择不被当成恢复成功。

## 收敛结论与待办

受测阅读、主题、紧凑布局及恢复流程可收敛。本轮只修已复现的提示问题，不继续更换风格或增加功能。

- 待实机验收：原生 release 的启动、1/10 MB P95、滚动帧率、250 MiB 进程组私有工作集及 100 次切换。历史约 312.5 MiB 的观察仍需按 SPEC 空闲窗口重测。
- 待实机验收：首次非系统盘数据目录选择、取消退出、完整迁移/中断恢复、全程系统盘写入、真实文件监听/拖放/关联打开，以及系统缩放、Narrator 和减少动效偏好。
- CI 安装审计即使成功也不能代替上述验收；既有报告 specPassed=false 的边界继续保留。本机真实操作按用户要求暂停。
- 产品决定：正式名称仍为暂称 MD/MdReader；若未来需要编辑、云同步、多窗口或便携模式，另行确认范围。现有只读、配色、三栏及 Windows 11 x64 定位不需重新选择。

本轮不合并任何 PR、不发布 Release、不发送 Crosswalk 消息。
